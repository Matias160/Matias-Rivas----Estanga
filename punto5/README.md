# Punto 5

Formulario simple con validacion de nombre. No acepta numeros ni simbolos y guarda los nombres en `data/nombres.txt`.

El archivo `data/nombres.txt` existe siempre: se deja creado en el proyecto y tambien se prepara cada vez que inicia el backend.

```bash
npm install
npm run server
npm run dev
```

Para probarlo completo, dejar `npm run server` abierto en una terminal y ejecutar `npm run dev` en otra.
