# Inicio - R1

El trabajo esta separado en proyectos independientes:

- `punto1`: Hola mundo.
- `punto2`: Tarjeta de presentacion con props e imagen local.
- `punto3`: Contador.
- `punto4`: Lista de tareas.
- `punto5`: Formulario validado con backend que guarda en TXT.
- `tateti`: Punto extra con tablero, historial, reinicio y modo dia/noche.

## Como ejecutar un punto

Entrar a la carpeta del punto elegido, instalar dependencias y ejecutar Vite:

```bash
cd punto1
npm install
npm run dev
```

En `punto5`, abrir dos terminales:

```bash
npm run server
npm run dev
```

Cada proyecto usa React 19, Vite, glassmorphism, modo dia/noche, responsive y ancho maximo de 1200px.
